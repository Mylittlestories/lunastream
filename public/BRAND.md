# LunaStream Brand Assets

This directory contains brand assets for LunaStream.

## Logos

- `icon-512.png` - 512x512 app icon (primary)
- `icon-192.png` - 192x192 app icon (PWA)

## Colors

- **Primary:** `#7c3aed` (Purple)
- **Background:** `#0b0b1a` (Dark Navy)
- **Text:** `#ffffff` (White)

## Usage

Please use these assets when referencing or linking to LunaStream. For any other brand usage, please contact the maintainers.
